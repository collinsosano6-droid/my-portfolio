Student Developer Portfolio Website.

A clean, modern, and fully responsive personal portfolio website built using pure HTML5 and CSS (no JavaScript or external frameworks required). Designed to showcase skills and  projects.

Overview 🔍

This project is a personal developer portfolio created to highlight the content learnt, technical skills, and featured projects. By relying strictly on HTML and CSS, it demonstrates a strong foundation in semantic markup, responsive layout techniques (CSS Flexbox and Grid), and clean design principles without the overhead of heavy scripts.

✨ Features

* 100% Vanilla Code: Built entirely with HTML5 and CSS—no JavaScript or CSS frameworks (like Bootstrap or Tailwind).
* Semantic HTML5: Uses modern elements like <header>, <main>, <section>, <article>, and <footer> for better accessibility and SEO.
* CSS Custom Properties (Variables): Easily manage global color schemes, typography, and spacing from a single root block.
* Pure CSS Interactions: Smooth hover effects, transitions, and active states built with native CSS pseudo-classes.

🛠️ Technologies Used

* HTML5: Page structure, semantic landmarks, and form inputs.
* CSS: Styling, layout architectures (Flexbox/Grid), variables, and responsive media queries.

🚀 Getting Started

To run this project locally on your machine, follow these simple steps:

1. Clone the repository:

git clone https://github.com

1. Navigate to the project folder:

cd your-portfolio-repo

1. Open the project:
  * Double-click index.html to open it directly in your default web browser.
  * Recommended: Open the folder inside Visual Studio Code and use the Live Server extension for real-time reloading during edits.

  🎨 Customization Guide

Personalize this template to make it your own:

1. Update Content: Open index.html and replace placeholder strings (like [Discover Collins], bio paragraphs, and social links) with your personal details.
2. Change Colors: Open css/index.css and modify the :root variables at the very top of the file:
3. Add Projects: Duplicate the project card HTML blocks in the portfolio section and update the image sources, project titles, descriptions, and live/GitHub links.
4. Swap Images: Replace the profile and project placeholder graphics inside the assets/images/ directory with your actual visual assets.
